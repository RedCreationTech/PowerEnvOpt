# v5 可复现验证

应用本身零第三方运行依赖，以 `npm start` 启动本机后端。真实 AI、Wiki 与评测不能通过双击 HTML 验证。

## 环境与执行

应用要求 Node >=18。本轮自动化使用 Node v24.19.0、jsdom 30.1.3。该 jsdom 版本需要 Node ^22.22.2、^24.15.0 或 >=26.0.0；安装测试依赖时应使用支持版本。

```sh
npm install --prefix tests --ignore-scripts
npm run check
npm test
```

根目录 `npm test` 包含全部 CJS 业务/DOM 测试及 `tests/*.test.mjs` 的后端/Wiki/评测测试。没有模型密钥也能运行；测试只使用临时目录、显式假响应或本机 HTTP 假模型，不会联系真实供应商。

- 既有套件覆盖页面/存储/数据一致性、角色守卫、工单闭环、质量门禁、失败复测、独立验收、取消/重开、迁移与右抽屉上下文。
- `real-ai-ui.cjs` 覆盖真实 AI UI 适配、人工采纳不推进流程、密钥不持久化浏览器、Wiki链、未分派工程师拒绝、异步响应切换工单/身份竞态。
- `server-test.cjs` 启动真实回环HTTP服务，检查主机、同源、CSRF、配置脱敏和静态资源限制。
- `backend-ai.test.mjs` 验证供应商端点、独立配置、结构/引用、超时、重试、输出大小、真实模型标识与安全错误。
- `backend-integration.test.mjs` 贯穿 HTTP API → 实际适配器 → 本机假模型 → 实际 WikiStore，验证四类AI动作、无匹配、编译/审核/发布和取消。
- `wiki.test.mjs` 验证源资料/图谱/适用性、原始导入、审核发布、修订/历史、过期引用拒用、并发保护、路径和元数据注入。
- `evaluation.test.mjs` 验证金标不进入提示词、固定哈希、严格边界、无效输出、失败分母、序列内R²、语义元组、取消和报告持久化。

`*results.json` 为业务套件输出；重跑会更新。根目录测试报告说明完整计数与边界。测试中的理想答案适配器只验证评分器，不是供应商模型结果；不能把测试PASS当成R08–R11模型达标。

## 覆盖边界

DOM模拟使用jsdom，模拟dialog、滚动、下载等；不等于真实浏览器布局/焦点/键盘/下载验证。本轮真实回环HTTP通过，但独立云浏览器访问执行器回环地址返回连接拒绝，未完成真实浏览器E2E。未做真实供应商、国产平台、真实硬件、生产容量/性能或现场节能验收。
