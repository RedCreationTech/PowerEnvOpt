## 实际HTTP验证

主验证进程真实启动 server.mjs 于 127.0.0.1:4199，再通过本地 fetch 检查：/、/app.js、/styles.css、/docs/data-sources.md 均返回HTTP 200及正确MIME；不存在资源返回404；POST /返回405。验证后服务器正常停止。

这是实际静态服务和HTTP响应验证，不代表浏览器已完成CSS布局、脚本加载、文件保存或交互渲染测试。
