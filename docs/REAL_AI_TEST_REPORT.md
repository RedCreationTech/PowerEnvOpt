# v5.0.0 真实 AI 本地原型：验证报告

验证日期：2026-10-20。执行环境：Node v24.19.0、jsdom 30.1.3。应用运行要求 Node >=18，DOM 测试要求 jsdom 支持的较新 Node。原始远端基线提交：9318ff3d633b323c4225a701315b3066604b99f2。

## 验证范围

- `npm run check`：17 个应用/后端/评测模块语法检查。
- `npm test`：业务/DOM 142 项检查或分组，单按钮冒烟 118 次，真实本机回环 HTTP 安全 20 项，Node 后端/Wiki/评测测试 62 项，总计 342 项检查/分组。不同分组粒度不同，不能解释为 342 条真实浏览器业务流程。
- 后端 16 项单元测试：独立双供应商配置、密钥权限和脱敏、端点隔离、结构/引用、大小/超时/重试、Qwen 非思考参数、实际服务模型标识及不变的历史引用快照。
- HTTP 集成 6 组：API→实际适配器→本机假模型→实际 Wiki，贯穿四种 AI 动作、无适用资料、原始导入/编译/人工审核发布、失败响应和评测取消。
- Wiki 16 项：实际链接/反向链接、严格设备族/型号/版本、不可变原始资料、候选隔离与审核发布、修订历史、并发/过期来源、元数据注入，以及删改原始资料失效。
- 独立评测 18 项：冻结哈希、输入与答案分离、严格阈值、非有限/错误输出、失败样本保留、序列内R²、语义匹配元组、取消和报告恢复。
- 数据导出 1 项：逐条输入严格等于输入投影、金标独立、每文件哈希一致、零模型调用。
- Wiki 链路 5 项：实际检索到假模型到引用校验、无答案泄露、伪造引用/超时失败、未运行状态明确。
- 新真实 AI UI 套件共15项，含未分派工程师拒绝、切换工单/身份时迟到响应丢弃、人工采纳不推进业务、真实 SVG 图谱及历史引用不随当前 Wiki 改变。

## 不使用真实供应商得出的实测结果

开发期间没有读取用户现有凭据，没有填写真实 API Key，没有调用 DeepSeek/Qwen 付费推理。所有供应商传输测试使用可控假响应或本机假 HTTP 服务，不能据此宣称任一云模型真实连通或达标。

## 安全与独立复核

本机服务只绑定127.0.0.1；配置修改要求同源Origin、Host及CSRF，静态资源白名单不公开 `.runtime/`、后端代码、测试答案或配置模板。配置采用独立提供商profile，Key只在服务器保存，POSIX目录700、文件600。公开配置只有hasKey，不返回明文。

新增知识页面仅在明确人工审核和发布后参与检索，已改变/丢失来源会使关联知识失效；缺少型号或版本不做跨范围匹配。模型建议不能自动审批、派单、操作设备或关闭。独立只读复核对跨版本混用、候选型号扩张、删除原始来源和历史引用变更分别建立回归。

项目文件范围执行私钥/常见供应商Key/GitHub Token模式扫描；空密钥模板验证通过。扫描不是数学上的无泄漏证明，不扫描与任务无关的用户或环境凭据。发布与压缩包排除运行目录、依赖目录和临时文件。

## 未完成的验收与限制

- 真实浏览器：代码执行器回环HTTP正常，但 dot 云浏览器访问该回环地址得到 `net::ERR_CONNECTION_REFUSED`，未验证真实浏览器布局、键盘焦点、下载和响应式表现；没有操作用户电脑或绕过网络限制。
- 真实供应商：需要用户按账号地域/模型权限配置并主动测试；非流式JSON模式兼容范围见 provider-compatibility.md。
- 真实指标：R08定义、温度20°C归一化范围仍为临时测试协议。合成样本未作实站抽样/专家金标/统计置信区间，任何合成集通过都不代表真实场地达标。
- 无真实硬件、训练、生产身份授权、多人共享数据库、不可篡改审计、200客户端/百万点容量、国产平台兼容或可靠性/节能现场验收。
