# v4.0.0 工单底座：验证报告

验证日期：2026-10-17。运行时仍为纯前端合成数据演示，无后台 API、真实模型或设备控制。

## 当前实现

- 场景告警与普通告警接管时立即创建唯一工单，抽屉与工单中心立即显示编号；重复接管不重复创建。
- 工单中心有新建表单、站点/状态筛选、状态计数、列表和右侧详情。人工维护、预测性维护、预防巡检及容量变更可主动建单，无需故障告警。
- 生命周期：待分析 → 待方案审批 → 待派单 → 待接单 → 处理中 → 待复测 → 待验收 → 已关闭；另有取消、重开、审批退回、验收返工和失败复测。
- 同一编号关联原始证据、知识版本、分析、决策、派单、检查、复测、验收、案例和审计。批准与派单分开，执行人固定，主管独立验收。
- 三个场景继续保留四阶段 AI 辅助决策、知识来源及条件风险分析；普通工单也可提交分析、保留知识快照和执行记录。
- 旧版已接管但未建单的记录补建一次；使用“迁移补建 / 版本迁移”标识，不伪造历史人工操作。有效工单为权威来源，兼容事件视图从工单重建。
- 信号复测恢复与业务关闭分别记录。质量无效时不允许可信诊断、审批或复测通过；恢复质量后须重新分析。关闭后重开保留历史案例记录。
