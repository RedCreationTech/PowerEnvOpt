# 红创科技 · 电源动环 AI 智慧运维 v3

## 本次交付

正常模块优先：总览、资产目录与拓扑、实时监控、告警列表、工单列表、设备健康、能耗、AI 问答、知识库、数据质量、接入与审计均直接展示，不再折叠到“原有功能”区域。点击实际资产、告警或工单打开右侧详情，保留背景页筛选和位置。

顶部只有一个模拟身份选择器。五个岗位、六名固定人员读取同一浏览器数据，显示不同首页、菜单、待办与操作。身份选择不是登录系统，前端检查不能作为生产安全权限。

## 启动

直接打开 `index.html` 可离线运行。也可运行 `npm start`，打开 `http://127.0.0.1:4173`（端口见 server.mjs）。无需运行时依赖、后台 API、CDN、远程模型或设备连接。官方资料只在用户主动点击时打开。

## 岗位与具体责任

| 固定人员 | 工作重点 | 可执行动作 |
|---|---|---|
| 刘值班 · 值班监控 | 运行总览、告警、监测 | 接管告警、写依据、请求诊断、普通告警建单及升级 |
| 王工 / 赵工 · 维护工程师 | 本人的执行待办、资产、诊断 | 辅助诊断；只接受和处理分派给本人的工单，检查、提交、复测 |
| 陈主管 · 运维主管 | 待审批、分派、独立验收 | 选择方案、明确派给王工或赵工、暂缓/退回、验收闭环 |
| 周分析 · 可靠性分析 | 诊断队列、健康、能耗、知识 | 带引用辅助诊断、回顾案例、审核管理员提交的模型状态 |
| 林管理员 · 系统管理员 | 接入、质量、拓扑、审计 | 模拟配置、质量标记、关系编辑、模型发布/回滚、本地演示重置；无业务验收权 |

菜单按岗位展示，但详情可以只读追溯关联记录。操作函数再次检查当前身份、业务状态、有效证据以及工单人员 ID；不能填写一个审核人名字绕过职责。所有演示人员均可查看全部三个站点；站点选择器是浏览范围筛选，不是生产数据权限隔离。

## 约 5 分钟演示：同一事件跨岗位交接

三个真实入口位于原有设备与告警中，不是独立的向导页面：

| 主题 | 资产 | 告警 | 事件 |
|---|---|---|---|
| 电池劣化提前干预 | HC-BJ-002 | AL-20261017-002 | EV-BAT-101 |
| 制冷热点预测排查 | HC-SH-003 | AL-20261017-009 | EV-AC-201 |
| 扩容前配电风险审查 | HC-SZ-004 | AL-20261017-016 | EV-PDU-301 |

1. 以“刘值班”打开告警中心，搜索上表告警。点击“查看证据”，在右抽屉“建议与处置”写依据并确认接管，再写说明、提交诊断请求。告警确认不等于恢复。
2. 切换“周分析”，首页出现同一事件。打开详情，在“监测证据”查看原始快照，再在“AI / 知识”生成固定规则辅助诊断。来源、版本、适用范围、竞争假设与边界都在本详情内。
3. 切换“陈主管”，待审批队列出现该事件。在“建议与处置”填写依据、选择方案和具体工程师。可先暂缓或退回；批准时自动创建唯一工单并分派。
4. 切换未被指派的工程师，不能接受或写检查记录；切到被指派人，打开本人待办并接受工单。完成全部检查项、填写记录后提交复测。
5. 先回放失败证据，确认返回排查、失败历史保留。再次完成检查，回放通过证据。此时当前测点由复测数据恢复，但告警业务状态仍为处理中，工单等待独立验收。
6. 切换“陈主管”，核对前后证据后填写验收依据并关闭；也可以退回返工。执行人不能自行验收。关闭后告警、工单、健康、总览与知识案例引用同步更新。
7. 知识案例是带完整轨迹的本地回顾材料，不自动发布为通用知识规程。重新打开设备时仍可看到原始异常、失败/通过复测及所有人的记录。

每条旅程都可独立操作，刷新或切换角色不会重置进度。详情可通过关闭按钮、Esc 或点击遮罩退出；背景筛选、分页和滚动不因打开详情而重置。关闭后恢复来源焦点。窄屏采用全宽详情。

## 其他原有功能

- 36 台虚构资产、3 站点、288 模拟测点、18 条初始告警；搜索、筛选、分页、导出、拓扑关系及版本记录继续可用。
- 普通告警可由值班人员接管和建立待分派工单；主管分派后，指定工程师接单、排查，主管批准处置，工程师记录处置与复测，主管验收。普通工单支持有原因的取消、重开和退回，保留历史。
- 监控页展示所选设备当前合成测点；场景触发时的历史证据位于详情，复测不会覆盖原始快照。
- AI 问答仍为本地关键词匹配；有来源则引用，无来源则拒答。没有真实语义匹配或生成式推理。
- 模型中心由管理员推进到待审批、分析人员审核、管理员继续发布；只有本地状态变化，不运行模型。
- 接入配置为浏览器模拟参数，不填写 IP、凭据、密钥，不扫描网络。
- 管理员可在场景“监测证据”中切换有效/缺失/迟到，验证预测、审批与复测质量门禁；恢复有效数据不自动批准。

## 数据与状态

- `app.js` 提供原有模块与数据；`workflows.js` 提供岗位协同、共享记录、守卫和统一详情；`styles.css` 为响应式界面。
- 全部数据仅保存在当前浏览器 localStorage，禁用存储时降级为内存模式。无跨设备协同、服务端认证或不可篡改审计。不要输入真实敏感信息。
- 从 v2 切入时，缺少固定人员所有权的旧联动场景被安全重建并提示；保留原有资产、配置及非联动记录，不将旧自由填写角色当作可信审批。
- 告警接管、复测恢复、业务关闭相互区分。最新通过复测驱动当前合成测点，主管验收只关闭业务记录并回写案例。退回返工不凭空撤销已有测量证据。
- 所有阈值、趋势与复测为合成数据；85% 规划线是场景自定值，不是行业统一阈值；区间和健康分数不是模型准确率或故障概率。

## 4. 原始要求映射

依据父项目《7011031111 电源动环系统 AI 智慧运维：详细需求分析与软件方案设计》及其原文需求基线。

| 编号 | 原始指标 | 本交付对应展示 / 需要后续完成 |
|---|---|---|
| R01 | 国产化运行环境部署 | 审计→指标映射；本前端无远程依赖，但未在指定国产 CPU、OS、数据库、推理平台实测 |
| R02 | 总处理容量 >100万点 | 明确展示实际只有 288 模拟测点；需后续真实采集/存储容量验收 |
| R03 | 扩展处理容量 >1000万点 | 仅目标映射；需后续横向扩容和迁移测试 |
| R04 | 2000条并发事件/秒存储 | 18 条初始合成事件；没有吞吐或持久化压测 |
| R05 | 200个以上客户端同时访问（≥200） | 单浏览器本地状态；没有多客户端并发验收 |
| R06 | 单页面响应时间 ≤3秒 | 需要指定硬件、网络、数据量、页面与冷启动口径测试；静态原型不证明系统指标 |
| R07 | MTBF >50000小时 | 仅需求展示；不以短期演示或静态测试证明可靠性 |
| R08 | 设备性能预测精度 >0.97 | 健康分数为合成场景数字，非准确率；精度统计量与测试集待确定 |
| R09 | 温度与能耗预测误差 <5% | 合成曲线与基线，无真实预测误差评测，两类任务需分别验收 |
| R10 | 语义匹配准确率 ≥94% | 关键词规则未测语义准确率，需独立标注测试集 |
| R11 | 大模型辅助预测性维护 | 展示证据→建议→人工工单闭环；无大模型服务或模型运行 |

严格“大于”不等于“大于等于”。“200个以上”按包含本数解释。本项目没有把建议测试余量当成原始要求。


## 生产接入前
