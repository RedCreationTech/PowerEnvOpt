# 红创科技 · 电源动环 AI 智慧运维

离线可用的中文纯前端交互项目。品牌为红创科技，需求编号 7011031111。

> 全部为模拟数据；没有设备连接、后台 API 或真实 AI 推理。原始需求中的性能、容量、预测准确率与可靠性是目标，不是本项目实测成绩。不要用于真实电气安全判断或现场控制。

## 1. 启动

### 方式 A：直接打开（推荐）

完整解压 ZIP，双击 `index.html`。页面使用普通脚本，不使用 ES Modules、fetch、CDN、远程字体或第三方库；无需安装 Node、npm 或其他依赖。

请保持 `index.html`、`styles.css`、`app.js` 的相对位置。个别浏览器限制 file:// 的 localStorage 时自动使用内存模式并显示提示，关闭页面即失去更改。

### 方式 B：本地静态服务器

安装已受信任来源的 Node.js 18 或更新版本后，在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。不需要 `npm install`。按 Ctrl+C 停止。端口占用时可设置 PORT，例如 macOS/Linux：`PORT=4180 npm start`；Windows PowerShell：`$env:PORT=4180; npm start`。

`server.mjs` 仅从 127.0.0.1 提供静态文件，仅处理 GET/HEAD。它不是业务后台，没有任何设备、模型或数据库 API。应用全部业务演示仍在浏览器内运行。直接打开与 HTTP 打开的浏览器存储通常不同。

## 2. 推荐演示路径

1. 运营总览：查看设备、测点、告警、健康指数与站点；切换站点筛选。
2. 告警中心：打开 `AL-20261017-001`，填写原因并确认；再次打开、填写原因，创建工单。
3. 工单工作台：打开关联 `WO-20261017-001`，每一步填写记录并推进。流程为待分派 → 已分派 → 已接单 → 排查中 → 待审批 → 处理中 → 待复测 → 待审核 → 已关闭。
4. 待审批与待审核阶段需填写不同于操作人和负责人的演示审核人。待复测必须明确通过/不通过；不通过退回排查。支持取消、驳回、关闭后重开。关闭工单同时更新告警为已关闭。
5. 实时监控与设备健康预测：选择相同设备 ID 查看测点/趋势；选择有质量问题的设备，观察预测阻断。
6. AI 运维助手：提问“UPS 温度偏高怎么排查”，查看固定规则建议与演示知识引用；问无来源问题会拒答，控制指令不执行。
7. 模型中心：候选 → 影子 → 待审批 → 灰度 10% → 生产演示；填写独立演示审批人；生产或灰度状态可回滚。
8. 审计与需求指标：查看刚刚的操作记录及完整目标映射。可导出 CSV/JSON，或切到“数据与本地存储”重置演示。

## 5. 数据、设备与知识边界

- 3 个虚构站点：北京亦庄、上海张江、深圳南山；36 台虚构设备；每台 8 个模拟测点，共 288 点；18 条初始告警。
- 设备族：UPS、蓄电池组、精密空调、配电柜、温湿度传感器、柴油发电机。型号均为 `HC-` 演示型号，不冒用厂商实际产品标识。
- 官方公开参数与协议资料只用于启发量纲和常见工况，具体来源、访问日期与不能推出的结论见 `docs/data-sources.md`、`docs/mock-recommendations.json`。
- UPS 有功功率按 40 kW×负载率计算；精密空调 30 kW 制冷量与 8.2 kW 输入电功率分开。柴油机待机输出功率/转速为零，输出频率显示不适用而非假定 50 Hz。
- 初始时钟：2026-10-17 09:45:00 Asia/Shanghai，即 2026-10-17 01:45:00 UTC。顶栏使用 UTC，事件详情标明北京时间。点击模拟推进只增加 5 分钟，不后台自动跳动、不使用随机数。
- 图表由固定公式生成；设备温度曲线以所选设备场景值为锚点；预测阴影为固定 ±2°C 演示带，不是统计置信带。示例健康分数不是精度、故障概率或安全保证。
- 日累计能耗以场景初始值加恒定模拟功率×时间计算，手动推进时钟会增加模拟电量，不读取真实电表。能耗分系统按比例分解；PUE 与基线偏差也是场景值，不是节能承诺。
- 3 处质量异常分别为迟到、缺失、时钟漂移；迟到与漂移各影响一个温度点，离线设备全部 8 点缺失，共 10 点异常。质量问题设备的预测被阻断。其余 278 点为有效模拟值。
- 知识条目 `KB-DEMO-UPS-001`、`KB-DEMO-AC-001`、`KB-DEMO-DQ-001` 为原创演示脚本，不是厂家原文、官方维修授权或实际手册摘录。
- 没有电源控制接口、分合闸、远程切换、保护定值修改或消防联动。

## 6. 本地存储与隐私

使用 localStorage 键 `hongchuang-power-demo-v1` 保存演示状态。没有遥测上报、在线分析、外链脚本或自动网络请求。

清除浏览器数据、换浏览器、切换 file:// / HTTP 源、使用隐私模式均可能丢失或隔离更改。禁止存储不可恢复时自动使用内存。localStorage 可被用户修改，不是加密数据库、权限系统、不可篡改审计或生产备份。

“审计与需求指标 → 数据与本地存储”提供 JSON 导出与二次确认重置。导出文件含使用者输入的演示备注，应自行保管。不提供任意 JSON 导入，避免把未校验数据注入状态。

CSV 对逗号、双引号、换行做转义，对 =、+、-、@ 开头的内容加文本前缀以减少公式注入风险。界面用户输入使用 HTML 转义；本项目仍不是完整生产安全产品。
